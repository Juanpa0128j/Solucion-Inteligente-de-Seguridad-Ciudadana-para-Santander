## Solución de Problemas

### Error al cargar la base vectorial
Verificar que existe la carpeta `vectores/` ejecutando primero `ingesta.py`

### Respuestas vacías o irrelevantes
- Revisar que los PDFs en `data/` contienen información relevante
- Verificar la calidad de los documentos fuente

### Error de API Key
Asegurarse de que el archivo `.env` existe y contiene `LANGCHAIN_API_KEY` válida
